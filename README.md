# FixIt Dispatch Backend (Week 1)

1. Copy `.env.example` to `.env` and fill in MONGO_URI and JWT_SECRET
2. `npm install`
3. `npm run seed`   (fills demo data)
4. `npm run dev`    (starts the server on http://localhost:5000)
